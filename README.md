# Personal Object Detection and Recognition

## Overview
This project trains a computer vision model to detect and recognise me in images.
It is part of the AI & ITEL course and covers the full machine learning pipeline:
data collection, annotation, training and evaluation.

## Objectives
- Collect a varied image dataset of myself
- Annotate the images with bounding boxes
- Train an object detection model using Ultralytics YOLO
- Evaluate the model with a confusion matrix, precision and recall
- Test the model on new, unseen images

## Dataset
- First batch: photos of myself taken at different angles, distances,
  lighting conditions and backgrounds, so that the model generalises
  instead of memorising one setting.
- Images are stored in Google Drive (not in this repository).
- Annotation tool: Make Sense (makesense.ai), exported in YOLO format.

## Tools and Libraries
- Ultralytics YOLO: object detection
- Make Sense: data annotation
- Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn
- Ollama with Llama 3.2 1B: local language model
